# Digital Oracle Local Workbench

See the [project introduction and setup guide](../../README.md) for installation, features, privacy exclusions, and limitations.

Run from this folder after creating `work/oracle-venv` at the repository root:

```sh
../../work/oracle-venv/bin/python server.py
```

Open http://127.0.0.1:8765. The service is local-only and requires your own authenticated Codex CLI. Runtime state and generated reports must remain outside version control.
