# Digital Oracle 方法對照

2026-09-30，參考公開 main 分支的 SKILL.md、references/providers.md 及 provider 程式。

原作：https://github.com/komako-workshop/digital-oracle/blob/main/SKILL.md

原作要求至少三個互補維度、逐個訊號選擇、時間對齊、共振與分歧分析，以及分層數據表、情境機率和監察條件。公開倉庫主要是 Python providers 與 agent skill；目前檢視的 main 未包含截圖的完整網頁前端。

原本本地版本限制五個來源、一個 ticker 和搜尋詞、400–700字，以及禁止表格。這些本地限制不符合原作的完整分析要求。

本次改動：

- 每個訊號各有來源、代號／搜尋詞、分析層、理由及時間窗口；上限40個，並行4個；相同查詢去重。
- Yahoo 一般完整252筆日線，明確價格門檻的目標資產可達約五年，先在本機計算5／21／63觀察期回報、年化歷史波動及最大回撤，計算所用完整價格序列亦保留在JSON。
- CFTC 可查不同商品，Kalshi 只接受明確支援系列；不以聯儲合約回答地緣事件。
- 完整報告包括分層訊號表、共振、矛盾、時間分層、情境、概率範圍、核心推理及監察条件。
- 原作部分敘述把市場效率視為絕對。本地版本保留分析方法，但不採用「價格必然包含所有真相」的假設。
- 概率區分市場隱含、未經回測校準的主觀情境估計、關鍵參數未識別的假設情境示例，以及資料不足。困難但有金融證據約束時優先給有明確假設的初步中心與寬範圍；不預設固定低機率。情境數字檢查合計100；所有引用必須對應已知查詢；證據表只接受成功回應，失敗查詢可在限制中如實引用。
- 頁面顯示全部查詢的成功／失敗，供核對原始證據；完整報告及證據可下載JSON。

仍有界限：模型估計不是經歷史回測校準的預測系統；搜尋摘要未核對原頁；免費資料來源可能缺失或延遲；連通測試不代表完整功能或商用再分發授權。SEC資料仍是申報索引，不能推定內部人買賣。CoinLore繼續免費替代CoinGecko；CME保持停用。

用戶進一步確認：只讀金融訊號，不受相關網上評論影響。規劃及報告提示詞均明確禁止新聞、分析師意見及社交評論成為判斷依據。網頁搜尋只提供待核實金融報價線索，未核實摘要不加入機率權重。

90分鐘改進迭代另加入FRED信用/實質利率、Deribit期權、固定市場CFTC52週、共同日期跨資產及利率變動相關性、歷史期末頻率、固定模型向前測試與壓力情境。上述計算支撐分析，但未把市場價格與任意事件概率建立經驗校準映射。
